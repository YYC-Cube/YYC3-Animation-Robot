### 4.2 安全建议

1. `NEXT_PUBLIC_*` 均为公开变量，符合最小暴露原则；后续若接入服务端密钥，须走 Server Action/Route Handler 且永不入 `NEXT_PUBLIC_` 前缀
2. Spline 场景 URL 为外部 CDN 资源，建议在生产配置 CSP `frame-src`/`script-src` 白名单
3. Dependabot 已产生配置更新 PR，建议开启自动合并策略（patch 级 + CI 绿）
